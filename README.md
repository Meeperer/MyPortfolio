# Editorial Portfolio

A modern, elegant portfolio website for Lord Mandell Esguerra (Meeperer).

## Quick Start

### Option 1: Using Python (Recommended)
```bash
python -m http.server 8000
```
Then open `http://localhost:8000` in your browser.

### Option 2: Using the Start Script
Simply double-click `start.bat` (Windows) to start the server.

### Option 3: Using Node.js
```bash
npx http-server -p 8000
```

### Option 4: VS Code Live Server
Install the "Live Server" extension in VS Code, then right-click `index.html` and select "Open with Live Server".

## Features

- Modern, responsive design
- Dark mode toggle
- Smooth animations and transitions
